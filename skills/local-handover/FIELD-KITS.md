# Field kits index

Simple list for the list field kits command. One bullet per kit. No entry here means no field coverage is claimed for that field.

## How to add an entry

- Record a kit the moment it is created or reused, before the run moves on.
- One bullet per kit.
- Each bullet gives: kit name, field in a few words, proof status (proven, draft, or proof failed), and kit folder path or repo URL if published.
- Never invent a kit, a path, or a repo link.
- Do not add run history, dates, run IDs, or proof detail here. The proof report holds that detail.
